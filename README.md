## What it does

`main.ts` writes a single sentence — the best advice the author ever
received — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> My grandfather, hands black with engine grease, told me: never trust a man
> who will not get his hands dirty, then handed me the wrench.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
